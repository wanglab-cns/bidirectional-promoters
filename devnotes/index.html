## Choice of RNA-Seq Analysis Pipeline

[2025-04-25] We chose the kallisto over STAR pipeline for the following reasons:
    1. The CCLE dataset is very large, and kallisto is faster for quantifying large datasets
    2. GDSC used kallisto, so we can compare our results with theirs

Technical Challenges

## Sample Name Format Issue

[2025-04-25] We encountered a problem with sample name formats between the CCLE and GDSC datasets.
    The CCLE dataset uses "BRCA-XX-XXXX" format, while the GDSC dataset uses "BRCA-XX-XXXX-XX".
    We had to write a script to remove the last two characters from the sample names in the GDSC dataset.

Project Decisions

Scope: pan-brain, pediatric first

[2026-10-13] The screen covers common pediatric brain tumor types in CBTN rather than all cancer types. Pediatric data comes first. Adult datasets (TCGA, CPTAC, GEO) are added once the pipeline works.

GENCODE v39 for the gene pair list

[2026-10-13] CBTN data is built on GENCODE v39. An earlier pair list used GENCODE v50, but mixing versions causes gene ID and coordinate mismatches downstream. The pair list is rebuilt on v39, and we count how many pairs are lost compared with v50.

Gene types

[2026-10-13] All gene types are kept, not only protein-coding genes, because microRNA and other non-coding partners are part of the question.

Clinical curation rules

[2026-10-13] We follow the ICB_Common curation standard, using ICB_Van_Allen as the example:

  • Never delete columns. Key variables go first in the standard order, and every original column follows, unchanged.
  • No imputation. Missing values stay NA. Variables we don't have (drug, response, PFS, stage, histology) are NA.
  • Survival time is in months; the event is 1 = death, 0 = alive. Overall survival only for now. Event-free survival waits until its event definition is clear, but its original columns are kept.
  • Sex is F/M. Age at diagnosis is age.
  • Tumor type and subtype names follow ONCOTREE. All six main tumor types sit at ONCOTREE level 3.
  • Each data release is versioned in its name, for example CBTN_2026.

No data on GitHub

[2026-10-13] This repository is public and holds code and documentation only. Publicly shareable processed data will go to Zenodo, with the link in the README.

Repository template

[2026-10-20] Set up from bhklab-project-template v0.14.1 with copier. The template's setup tasks were skipped because the repository already existed, so pixi.lock is created on the first pixi install.
